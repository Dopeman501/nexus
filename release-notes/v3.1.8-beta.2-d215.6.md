# Local D215 update: 3.1.8-beta.2-d215.6

Verified and installed on 5 November 2026. This local Windows build includes the previously accepted rotation, frame-cap and MP4 import changes alongside circular Panels and five hardware brightness levels.

Source revisions on `local/d215-beta.2`: dashboard `147dfb72b97885288f5b4ded7681c85da4cd4ca7`; service `13074898e878e897ccb9ce4a7aef158c51005e95`. The umbrella checkout pins both revisions. Generated packages and private operational backups remain excluded from Git.

## Behavior

- A D215-only **Panels** tab follows Widgets. Up to six independent round widgets can appear together, with individual settings, movement, square corner resizing, keyboard controls, and canvas/peer alignment and centering guides.
- Panels mode preserves the ordinary Widgets layout and background. Compatible installed round SDK widgets use the existing sandbox and settings lifecycle.
- Hardware brightness presets are **20%, 40%, 60%, 80% and 100%**, with confirmed device readback before the UI accepts a value.
- Rotation supports 0°, 90°, 180° and 270°. The effective saved cap controls both rendering and physical frame timing, up to the 60 fps model maximum. D215 MP4 import retains lower source rates and allows up to 60 fps; other panel imports retain their existing behavior.

Normal Nexus restart preserved the exact layout, active profile, retained Widgets and checked background fields, 0° rotation and saved 30 fps cap. The six-circle layout remains active at the user's request.

Physical throughput/CPU with six animated widgets and photometric brightness were not measured. The six-circle sample was physically checked at 0°; other composition orientations have deterministic/browser coverage, while all four physical angles were separately accepted on the earlier `.4` build. Deferred physical USB detach and driver-stall checks remain separate.

The pre-commit dependency audit reports 29 advisories in the unchanged web dependency graph: 1 critical, 12 high, 14 moderate and 2 low. Package manifests, lockfiles and the standalone Node server are unchanged by this update. These results do not establish a clean dependency audit.

Security review found that the critical [`proxy-addr` advisory](https://github.com/advisories/GHSA-jqcg-44mw-7w3h) requires particular IPv6 proxy-trust subnet configurations. The standalone Express server leaves proxy trust disabled and does not make security decisions using the client IP. The installed Windows `.6` package instead serves static assets through ASP.NET and contains no Node executable, Express modules or `server.js`. This finding does not block committing the verified D215 source. The baseline advisories remain unresolved and require a separate dependency refresh, including `proxy-addr` 2.0.8 or newer, audit triage, rebuild and regression checks.
